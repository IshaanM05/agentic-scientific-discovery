# Demo video script (60 seconds max)

Record the Streamlit app (`streamlit run app/streamlit_app.py`) with OBS or Loom at 1080p. Before recording,
run case T-0167 once with live research on, so the papers and briefs are cached and appear instantly on camera.
Speak at a relaxed pace: the voiceover is about 140 words.

| Time | On screen | Voiceover |
|---|---|---|
| 0:00–0:08 | Title card, then the raw light curve panel | "Telescopes find thousands of dips in starlight. Most aren't planets. Checking each one is slow, and the hard part is choosing which test to run next." |
| 0:08–0:15 | Sidebar: pick ★ "Leader flips mid-investigation: T-0167", show "Connected: gemini", press **Start investigation** | "Our lab treats each dip like a patient, with an AI diagnostic team modelled on House M.D." |
| 0:15–0:25 | Scroll to House's differential, then Cameron's **Live research** card with cited arXiv IDs | "House lists the suspects. Cameron searches arXiv live, and Gemini reads the abstracts. It can only cite papers it really found." |
| 0:25–0:38 | Press **Run to next decision** twice: Cuddy's test table, Chase's odd/even result, Foreman's SURPRISE + counter-experiment, House's REOPEN | "Cuddy picks the most informative test for its cost. Chase runs it. Foreman doesn't trust a surprise until a control experiment confirms it, and the leading diagnosis flips." |
| 0:38–0:48 | Press **Run to verdict**: posterior trajectory chart, verdict card with CI, then open "Reveal ground truth" | "Three flips later: starspots, 96 percent, with a credible interval and full provenance. The answer is revealed only after the verdict. Correct." |
| 0:48–0:60 | Benchmark tab: accuracy-vs-cost figure | "Across 240 blind cases, the team matched a standard checklist's accuracy at half the cost and sent fewer cases to humans." |

**Captions:** add burned-in captions with the same text (most jurors watch muted).
