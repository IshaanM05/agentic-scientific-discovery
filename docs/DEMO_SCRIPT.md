## Must not say
- "prior systems run no experiments" in general (Coscientist and A-Lab do); if comparing, name SciAgents only: as described in its method it generates and critiques hypotheses without running experiments, ours runs the experiment and lets the result change the next decision.
- "faster" / "acceleration" for steel (rule not met); "hard gate" for approval without the qualifier; anything from `runs/live2`'s first pick (tainted by a prompt example).
- That the e2-live planner adapted, hit the target, ran the critic's test or reached the approval step; it did none of these.
- Any LabLoop number before W2's rerun and the lead's live run exist.
