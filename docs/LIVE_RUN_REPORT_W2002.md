## Hypotheses (from the analysis records)
Falsified: H3 (Sn >= 0.3 gives T80 < 400 h; n = 5) and H1 (n = 4); each triggered a prior relaxation (stability, then bandgap). Qualified (holds with exceptions): H8 (counterexample Cs0.1FA0.75MA0.15Pb0.8Sn0.2I3, T80 409 h). Supported: H2, H7, H14, H15. The planner's final prose mis-described some of these (it says so itself), so the records, not the prose, are the source here. Hypotheses H7-H15 were written by the generator and labelled agent-generated by the arena; literature hypotheses are labelled literature. The Cs0.1FA0.9Pb0.6Sn0.4I3 bandgap surprise (z = -2.5) was queued for replication and re-queued as a standing PI rationale to the end; the record shows no replicate film of that composition.

## Observations and limits
- The textbook prior said few or no qualifying films; the simulator produced 12 spec-meeting films, so the run contradicts that prior inside this simulator only.
- The run stopped on LabLoop's own PI rule, so it does not show behaviour under budget pressure.
- Replication is two films per confirmed composition; T80 replicate spread was up to about 35% by the planner's reading.
- One sample on one world; no comparison to the rule-based scientist was made here.

Smoke run (budget 8, `runs/ll-smoke2002`): 5 films, 7.5 units, 2 spec hits, 2 rounds; the planner handed off to its sub-agents correctly.
