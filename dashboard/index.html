An AI scientist that decides which experiment is worth running next.

LabLoop is a team of agents that reads the literature, writes falsifiable hypotheses, designs films for a lab, reads the results, and changes its mind. The lab below is slow and costly on purpose, so every experiment has to earn its place.

      Lab time is the scarce resource

      Two synthesis stations run films for a day or more each. Agents never wait: ranking, re-fitting and critique happen while films anneal and age.

      Discoveries

      A film only counts after the judge sees it meet spec twice. Single hits stay candidates; a replicate that misses is recorded as not reproduced.

      How the loop is built

      The language model proposes and explains; a Gaussian-process surrogate decides where the next film gives the most information; the notebook remembers every failure. Swapping the lab adapter moves the same loop to a robot, a simulator or a biology screen.

      The lab is a replay

      Results come from hidden physics with noise, failed films and costs, built from published perovskite trends. It lets us run controlled comparisons; it is not a wet lab.

      The judge is a rubric

      Replication, sample size and physical sanity checks. In production it would be calibrated against expert verdicts before anyone trusts its confidence labels.

      Safety sits before hardware

      Every protocol passes a screen for restricted elements, toxic-metal handling and scale. Anything above level 2 waits for a human sign-off.
